# Agent Library

## How to use
1. Mở Claude Code trong thư mục my-crud-app
2. Chạy: claude --dangerously-skip-permissions
3. Dùng prompt phù hợp với agent bên dưới

## Agents

| Name | Purpose |
|------|---------|
| page-builder | Tạo Next.js page với TypeScript + Tailwind |
| api-builder | Tạo API route với Neon DB + error handling |
| search-filter | Thêm search/filter/sort cho items page |
